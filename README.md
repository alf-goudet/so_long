# Description

`so_long` is a project that introduces students to the field of Computer
Graphics, by having them create a simple 2D game with graphical elements
(images, sprites, tiles, etc.) that will be drawn by the computer on a window
and controlled with the keyboard and/or mouse.

The purpose of this project is for students to start being familiarized with
the inner workings of the windows on which graphical applications function,
as well as learning how to command graphical responses based on user input via
the keyboard and/or mouse.

## Overview

Students have the following at their disposal to get started:

- 	**The `MiniLibX`**: A small, simple library of C functions to create and
	manage windows for programs via the _X Window System (X11)_. It's purposed
	especially for students just getting started with X11.
